# MathStudio v0.1.7 — 冒険マップ版

小学校から高校数学までの技能を、Civ型の前提関係マップとして探索する個人用ブラウザ学習アプリです。自宅PCでのオフライン動作を前提とし、ユーザー登録・APIキー・サーバーは不要です。

## この版の新機能

- **明るいRPG風の外観：** 青空と浮遊島の背景、学年ごとの舞台名、金色のMASTERカード、ミニ花紋章、見やすいボタンとポップアップ。
- **4つの宝石を1輪の花に：** 青＝基礎力、赤＝速度、緑＝応用力、紫＝文章題。それぞれの進捗で花びらの発色を変えます。意味と点数は改変しません。
- **冒険Lv.とEXP：** 実装済み技能の初回受験・仮免・満点・MASTERの状態から表示用EXPを算出します。反復受験による無制限稼ぎをせず、成績や解放条件には影響しません。
- **全祖先の依存ルート：** 技能に必要な直接前提、さらにその前のすべての前提技能を、分岐・合流を含めて解析。全285技能で利用できます。
- **スタート地点と教材実装状況を区別：** グラフ上で最も先に学ぶべき未達技能と、現行15技能のうち実際に練習可能な技能を別枠で表示。
- **ツリー上でルート強調：** 技能を選ぶと前提線を一括強調。未達の前提は金色、仮免以上の前提は緑色。表示範囲外の前提もポップアップには掲載され、クリックでその学年へ移動できます。
- **従来の経路配置・固定学年見出し・拡大縮小を維持。**

## 利用

`MathStudio_v0.1.7_Standalone.html` をChrome/Edgeで開いてください。インターネットは必要ありません。旧版からデータを引き継ぐときは旧版でJSONを書き出し、こちらで読み込んでください。

## 範囲・注意点

スキルツリー：285技能・485依存辺。問題生成/採点：15技能のみ（270技能は未実装）。前提グラフは**研究・検証中の暫定案**で、教科書に忠実な完成体系ではありません。既存15技能のアンロックと完全MASTERはMathEngineの実装済み条件に基づきます。経路表示はその判定を変更しません。

進捗はローカルブラウザストレージに保存されます。バックアップJSONに学習内容・解答が含まれるので公開リポジトリにはアップロードしないでください。インストール不要で使える単独HTMLに、全ての画像素材を埋め込んでいます。
