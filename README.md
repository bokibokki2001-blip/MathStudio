# MathStudio v0.1.6 — 自宅PC向け算数・数学スキルツリー

**自宅PCでは [MathStudio_v0.1.6_Standalone.html](MathStudio_v0.1.6_Standalone.html) を保存してChrome/Edgeで開いてください。** インストールも通信も不要です。GitHub Pagesは学校のi-Filterで止められたため、自宅PC使用を前提とします。

## スキルツリー（v0.1.6）

- 小学校143、中学校66、高校数学76の**全285技能**と485前提関係を可視化（暫定案）。
- 同じ学年内でも前提技能→発展技能を**左から右へ段階配置**。学年・科目帯の幅は、内部の前提層の数に応じて変動します。
- 分野ごとに高さ帯をそろえ、前後の依存を反復整列して線の上下移動を削減。障害物がなければ**完全な直線**、ほかのカードにぶつかる場合のみカード間の通路へ迂回します。
- 小1〜3のリンク平均上下差が約539→170px、小4〜6が約504→163px。6表示範囲で延べ1,069経路のうち637本は直線。無関係なカードの内部を通る経路は0件（線同士の交差は残ります）。
- 左右スクロールは増えますが、無理な縮小はしません。必要な縦スクロールはツリー内部で行います。学年見出しは固定。検索、範囲切替、ズーム、選択時の詳細ポップアップとマウスホバーの前提線強調を搭載。

## 学習機能と保存

**練習問題・混合テスト・採点・4宝石・MASTERが実際に動くのは15技能のみ。** 残る270技能は「教材準備中」で、テスト開始はできません。表示用485リンクと実装15技能の評価用前提グラフは別物です。学力診断も15技能の試作範囲に限ります。

旧版からの移行時は旧版でJSONバックアップを取り、新しいHTMLの設定から読み込んでください。ローカルHTMLは保存先が変わる場合があるため、保存確認まで旧版を削除しないでください。公開GitHubに子どもの氏名・解答履歴・学習バックアップを掲載しないでください。

## ソースと検証

`index.html` は分割ソース `src/` を読み込みます。独立HTMLの生成は `python tools/build_standalone.py`。検査は `node tests/run.js`、`node tests/test_tech_tree.js`、`node tests/test_dependency_alignment.js`、`python tests/test_full_curriculum_ui.py`、`python tests/test_readable_map_ui.py`、`python tests/ui_smoke.py`、`python tests/test_regrade_ui.py` です。詳しくは `TESTING.md`。
