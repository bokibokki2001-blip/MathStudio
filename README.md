# MathStudio v0.1.2 — 自宅PC向け算数・数学学習アプリ

**最初に使うファイル：`MathStudio_v0.1.2_Standalone.html`（インターネット接続・インストール不要）。** HTMLファイルをWindows PCの任意のフォルダに保存し、ChromeやEdgeで開いてください。画面の「初回診断」から始めます。

**学習履歴の保存**：ブラウザのローカルストレージに保存されます。同じファイル・同じブラウザで使うのが安全です。場所を移動したりブラウザを変えたりする際は、先に「学習データを保存」でJSONを出力し、移動先で読み込んでください。保存領域は環境依存のため、定期的にJSONでバックアップを取得してください。

**技術ツリー**：小学1〜6年の列と4系統を持つ2Dマップです。15技能の実際の前提関係16本を表示し、分野の分岐・合流を確認できます。小5・小6は空の予定列。カードをクリックすると詳細が開きます。

**公衆GitHub Pages**：公開リポジトリにはアプリコード・説明文だけを置き、個人のバックアップJSONを追加しないでください。学校管理端末からのアクセス制限を回避するための変更ではありません。

# MathStudio v0.1.2 — Chromebook向けオフライン試作版

**初回診断から練習、混合テスト、宝石の成長、仮免・完全マスター判定までが動く、個人用のブラウザアプリです。**

## 使い方

1. **いちばん簡単なのは** `MathStudio_v0.1.2_Standalone.html` をChromeで開く方法です。ZIPを使う場合はZIPを展開し、展開後の `index.html` を開いてください（ZIPの中から直接開かないでください）。
2. 小学1〜6年の学年と起動月を選び、初回診断を受けます。学年は出題の初期位置の手掛かりです。
3. 4つの分野（たし算・かけ算・わり算・分数）で、それぞれ正解に応じて上の技能へ、誤答に応じて前提技能へ移動します。
4. スキルツリーで技能を選び、短い練習（その場で答え合わせ）または混合マスターテストを開始します。
5. 各技能のテストは、基礎・応用・文章題を混合した推定20〜30分構成です。途中で一時停止できます。
6. 「設定・バックアップ」または右上のボタンで、学習記録を**JSONに書き出して保管**してください。学校管理端末はブラウザ保存が消える可能性があります。

**単独HTML版と `index.html` 版ではブラウザ保存先が異なる場合があります。途中で切り替える際は先にJSONバックアップを書き出し、切替先で読み込んでください。**

ブラウザ以外のインストール、ログイン、APIキー、サーバーは不要です。ネットワークにアクセスするのは利用者が明示的に「Geminiへの質問を用意」を押したときに外部Geminiページを開く操作だけです（サイト閲覧が学校管理側で禁止されていれば利用できません）。

**学校管理Chromebookのファイル閲覧制限は端末によって異なり、実機での `file://` 起動は未確認です。**

## 評価ルール

- 混合テストの **基礎力** = 基本問題の正答率、**応用力** = 応用問題の正答率、**文章題** = 文章題の正答率。
- **速度** = `min(100, floor(100×目標時間÷実時間))`。目標時間以内なら速度100%です。速度の宝石は正答率と独立して表示し、合否は基礎力・応用力・文章題でも判定します。**完全MASTERには全問正解＋目標時間以内が必要**です。
- **仮免** = 上の4数値が**同じ1回のテストで全て75%以上**。一度認定された仮免は保持されます。
- **自己100%** = 同じ1回の混合テストで**全問正解かつ目標時間以内**。問題ごとにランダム生成した新しいセットを使用します。
- **完全MASTER** = 自己100%達成 + 試作グラフ内の**前提技能が全て完全MASTER**。前提未達なら「認定待ち」、後からそろえば自動的に連鎖確定します。
- 以前のテストで獲得した満点を寄せ集めても自己100%にはなりません。マスターを取得すると取り消しません。
- 初回診断（3問×技能の暫定探索）では**マスター認定を一切行いません**。初回診断のおすすめ技能へは特別に挑戦可能にします。

## 重要：初版の範囲

- **実装済み15技能**：小学1〜4年の一部だけ。小5・6年で初回設定しても、問題はこの15技能の範囲で探索されます。
- `reference/curriculum_285_v0.1.json`：既存の**285技能の暫定カリキュラム案**を参考同梱。**この285技能すべてがアプリで動くわけではありません**。学年/月と前提リンクも試作専用の簡略化です。
- 月別カリキュラム、難易度、目標時間は**仮設定**。公開学力調査の問題別正答率や教科書年間指導計画による校正はまだ行っていません。
- 問題生成は基礎・応用・文章題の3区分を必ず含めますが、細かい重要問題類型の網羅はまだできていません。
- 分数は `2/3` などのキーボード入力です。筆算マス目・図形操作・手書き・中学高校の出題・標準進度グラフは未実装。
- 文章題の自由式は一部の四則演算だけ対応します。単なる答え一致は原則マスター認定されず、式の意味を保証できない場合は「要確認」または不正解になります。PoCの制約は `HANDOFF.md` に記載。
- 個別適応型の間違い原因診断は未実装。初回診断では正誤による上下移動までを実装。

## 開発・テスト

- `python tools/build_standalone.py`：ソース変更後に単独HTMLを再生成。
- `node tests/run.js`：問題生成・採点・アンロック・初回診断の自動テスト（Node.js 22で検証）。
- `python tests/ui_smoke.py`：PlaywrightとChromiumがある環境で、画面の一連の操作を模擬テスト。テスト環境にブラウザの外部ページアクセス制限があるため、HTML/CSS/JSをテストページへ直接注入して確認しています。`file://` 起動そのものの検証ではありません。
- `TESTING.md`：実施した検証と未検証の詳細。

## 保存の注意

児童の回答・途中式はブラウザ内とバックアップJSONに保存されます。個人名などを入力しなくても使えますが、エクスポートファイルには学習履歴が含まれます。公開GitHubなどへ誤ってアップロードしないでください。個人用アプリのため、ブラウザ上のプログラムやJSONを改変した場合の不正防止機構はありません。

## v0.1.2 修正・旧版データについて

- 同じ数が2つ以上出る文章題（赤いシール1枚・青いシール1枚など）を `1+1=2` と解答した場合、数量を別々に扱って正解判定します。誤った式が偶然同じ値になる場合は不正解のままです。
- 速度の宝石を正答率と切り離し、目標時間以内なら速度100%と表示します。満点認定には全問正解も必要です。
- **既存の答案を保持したまま再採点**する処理を追加しました。旧版のJSONを新しい版で読み込むと、過去の「要確認」、宝石・仮免・MASTERの状態を再計算します（旧版に問題と解答が保存されている正式テストが対象）。
- **重要：ファイル名を変えるとChromeの `file://` 保存領域が別になる場合があります。** 旧版を開いて「学習データを保存」からバックアップJSONをダウンロードし、新版を開いて「設定・バックアップ」→「JSONバックアップを読み込む」で引き継いでください。バックアップが確認できるまで旧版ファイルや旧データを消さないでください。
