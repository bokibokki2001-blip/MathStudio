# MathStudio v0.1.8 — オフライン算数・数学の冒険マップ

Windows PCのChrome/Edgeで動く、アカウント・API・サーバー不要の個人用算数学習アプリです。1つのHTMLでオフライン利用でき、公開ページの `index.html` は同じ版の単独ファイルとして配布しています。

## 対応状況
- 暫定技能カタログ：全285技能、前提関係485本。
- **出題・採点可能：79技能（従来15技能＋今回64技能）**。小1〜4の基礎（数、引き算、時計、単位、図形、表・グラフ、小数、余り、概算、面積など）。
- 残り206技能はマップ・全前提経路のみ閲覧可能（教材準備中）。
- 各実装技能に基本・応用・文章題。4宝石による75%仮免・完全MASTERのルールを維持。
- 数式構造を確認する文章題は一部の加減算・乗法。図形・時計・単位などは最終結果のみ検証します。

## 自宅PCで使う
配布ZIPから `MathStudio_v0.1.8_Standalone.html` を取り出してブラウザで開いてください。GitHubの複数ファイルから開発する場合は、`index.html` を開いてください（GitHub上の起動ページは単独HTML版です）。

旧版から学習記録を移す場合は、旧版で **設定・バックアップ → JSONバックアップを保存**、新版で **JSONバックアップを読み込む** を実行してください。公開リポジトリへ学習記録JSONを置かないでください。

テスト・設計上の制約は `TESTING.md`, `SPEC.md`, `HANDOFF.md`, `CHANGELOG.md`, `START_HERE.md` を参照してください。教材の難易度とテスト時間はまだ教育的に校正されていません。
