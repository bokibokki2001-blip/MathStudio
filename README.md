# MathStudio v0.1.5 — 自宅PC用・オフライン数学スキルツリー

自宅PCのChrome/EdgeでHTMLを開いて使う個人用学習アプリです。学校管理Chromebookの制限を回避する設計ではありません。

## 新しい技術ツリー
- **全285技能・485本の前提リンク**を表示。小学校143技能、中学校66技能、高校数学76技能。
- 最上段カードが学年見出しに隠れる不具合を修正。学年見出しとスクロール領域を上下の別行に分離し、左右スクロールには見出しが追従します。
- 「小1〜3」「小4〜6」「小学校全部」「中学校」「高校数学」「全285技能」から表示範囲を選択可能。全285技能を検索して詳細へ移動できます。
- 高校は学年固定ではなく数学Ⅰ・A・Ⅱ・B・Ⅲ・Cの**科目別**です。
- ツリーの画面全体の縦スクロールはなくし、内容が多い場合はツリー**内部のみ**スクロールします。
- **練習問題・採点・4宝石・MASTERが動くのは15技能だけ**。他270技能は「教材準備中」で、練習/テストボタンはありません。

285技能と485リンクは学習指導要領の領域を参考に作った**未検証の独自カリキュラム案**です。既存15技能の試作習熟判定の前提関係を、485リンクに変更したものではありません。

## 使い方と保存
単独HTMLは別途配布する `MathStudio_v0.1.5_Standalone.html` を開いてください。GitHubリポジトリの `index.html` はウェブ表示用に同一のソースを内包しています。ソース版は `src/` を使用します。

前バージョンの学習履歴を移すときは、旧版で「学習データを保存」からJSONを書き出し、新版の「設定・バックアップ」から読み込んでください。**公開GitHubに児童の学習記録・バックアップJSONをアップロードしないでください。**

## 習熟のルール
基礎力・速度・応用力・文章題の4宝石を混合テストで評価。1回のテストで4項目75%以上なら仮免。全問正解＋目標時間内、さらに試作グラフの前提技能がすべてMASTERなら完全MASTER。時間内なら速度100%、正答率は別の宝石で評価します。

## 開発
`src/catalog.js` に全285技能・485前提関係を埋め込み、`src/skills.js` と `src/engine.js` は15技能の出題・採点を担当します。`python tools/build_standalone.py` で1ファイル版を生成できます。

`node tests/test_tech_tree.js` と `python tests/test_full_curriculum_ui.py` はグラフ、5画面サイズ、検索、見出しを検証。既存の11スイートの問題生成・採点テストも維持。自宅PC実機での起動・保存の永続性、270技能の教材化、前提構造の教育的正当性は未検証です。
